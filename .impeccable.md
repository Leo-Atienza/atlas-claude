# Design Context — ATLAS public repository

## Users

Developers evaluating ATLAS on GitHub, in a browser tab, deciding within about
thirty seconds whether it is worth cloning. A second, smaller audience arrives
looking to lift one piece — the hook layer, the proposal queue, the action graph —
rather than adopt the whole thing. Both need to reach a judgement fast, then be
able to go deep without leaving the page.

## Brand personality

**Precise · warm · unhurried.** It reads like a well-made technical manual rather
than a product launch. Confident enough not to shout, specific enough to be
checkable. Claims carry numbers, and the numbers are true.

## Aesthetic direction

Warm editorial, drawn from the celestial-atlas meaning of the name: a printed
plate from a star atlas or the faceplate of a measuring instrument. Hairline
rules, generous margins, an armillary sphere as the mark, small-caps metadata.

**Anti-references:** the purple-to-blue gradient on near-black that the previous
banner used, glowing accents, gradient-filled text, centered-everything layouts.
That look is the default costume of AI-generated developer tooling and says
nothing about this project.

**Theme: both.** GitHub honors `prefers-color-scheme` through `<picture>`, and the
audience is split. Dark is a warm near-black (`#0F0D0A`), never blue-black; light
is cream (`#FBF8F3`), never white.

## Palette

Inherited from `design-system/tokens/colors.ts` — an established system, honored
rather than reinvented. Paper and ink neutrals, one muted ochre accent
(`#B07D28` light / `#DDB562` dark). No second accent.

Light mode is a re-derived mirror, not an inversion: `#8F7F67` metadata and
`#B07D28` accent text both fail AA on cream, so light mode uses `#6B5E4B` for
small text and reserves `#8D6320` for accent text. Every pair was computed, not
eyeballed.

## Typography

System serif stack — `Iowan Old Style, Palatino Linotype, Palatino, Book Antiqua,
Georgia, serif`. Chosen under a hard constraint: GitHub renders README SVG through
`<img>`, so no web font will ever load. A serif that ships on virtually every
machine is the honest answer; the alternative is a wordmark that silently falls
back to something worse. Wide tracking on the wordmark and small-caps labels do
the editorial work that a display face would otherwise carry.

## Design principles

1. **Every number is checkable.** Counts in the README and banner are derived from
   the repo, not remembered. A stale count is a bug — the old banner shipped
   "282 skills · v2.5.0" against a v10 system.
2. **Scan in thirty seconds, then go deep.** Nine top-level sections; heavy
   reference material lives behind `<details>` so depth costs nothing up front.
3. **Left-aligned and asymmetric.** The title block sits in its own compartment
   beside the diagram. Centering everything is the reflex, not a decision.
4. **One accent, used sparingly.** The ochre appears on the rule, the sphere's
   center, and one tracked body. Accents work because they are rare.
5. **Honor the existing design system.** Tokens already existed; the job was to
   apply them, not to invent a look.
