# /wiki-lint

Run the persisted checker — never improvise scan code (the ad-hoc-script era caused CRLF false positives and heredoc-mangled paths; v10 F-07):

```bash
node ~/.claude/scripts/wiki-lint.js
```

The script is the single lint engine (one engine, two doors — wiki-manage LINT mode calls the same script). It CRLF-normalizes reads, skips auto-generated pages (`graph/`, `graphify-out/`, `session-log/`, hot.md, "Regenerated by" banner files), and reports deterministically: broken `related:` links, broken md-links, phantom index rows, missing frontmatter, stale pages (>90d), orphans, unresolved body wikilinks (info only — aspirational links are a vault convention).

## After the script

1. Present its findings table as-is (add `--json` for machine output). If empty: "Wiki health: all clear" + today's date.
2. **Ingest backlog** (separate check): `cd ~/.claude && node scripts/wiki-ingest-pending.js --report` — list raw drops awaiting `/wiki-ingest`, or "ingest backlog: clear". Compile is human-in-the-loop — never auto-compile.
3. Optional network check (interactive runs only, skip in scheduled runs unless asked): the stack-freshness pin scan in [skills/wiki-manage/SKILL.md](../skills/wiki-manage/SKILL.md) Mode 3 steps 4b/4c.
4. **Do NOT auto-fix** — Review-vs-Implement rule. Report only, await user instruction.
5. **Append to log.md** — `| {date} | lint | - | {issues_found} issues found |`
