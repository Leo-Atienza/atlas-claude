## Technical — if the brief is for dev-heavy contexts

**Atelier is a reusable design token + primitive component set for React/Next.js projects. Tokens (color, type, spacing, motion) are source-of-truth; components (`Button`, `Card`, `Input`, `Badge`, `Container`) read tokens via Tailwind v4 semantic classes. Dark mode flips through `[data-theme]` and CSS variables — no style duplication. Motion tokens are GSAP-compatible.**
